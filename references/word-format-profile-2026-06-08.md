# 2026 年 6 至 8 月 Word 格式画像

本参考根据 2026 年 6 月、7 月、8 月党建目录中的 22 份正式记录和 3 份学习原文提取。参数直接来自 DOCX 的 OOXML 样式表、段落属性和运行属性，不包含真实正文、单位名称、人员信息或活动内容。

本文件用于判断页面设置、样式名称、字体字号、字符间距、行距、段前段后、首行缩进和空段习惯。当前生成流程已经把这些参数固化为 `templates/standard-party-template.docx`，运行时不再要求读取往月 DOCX。本文件用于维护统一模板和核对生成结果。

## 结论摘要

- 全部正式记录均为 A4 纵向页面。正文主体通常为上下页边距约 2.54 cm、左右页边距约 3.17 cm、页眉距离约 1.5 cm、页脚距离约 1.75 cm。
- 正式记录不是单一模板体系。常规会议、学习和谈心谈话主要使用 `党建标题`、`党建标题1`、`党建正文`；部分主题党日和支部书记讲党课使用 `全文一级大标题`、`正文一级标题`、`正文二级标题`、`正文 文本`。
- 段前、段后通常都是 0 pt。段落之间的距离主要来自固定行距、标题样式、空段和人工换行，不能额外统一增加段前段后。
- 有效字符间距为 0 pt 或未单独设置。样式里的 `w:kern` 是字距调整启用阈值，不是额外字距，不应把它误写成加宽或压缩字符。
- 常规记录的正文通常为 16 pt 仿宋，首行缩进 640 twips，约 1.129 cm，相当于 16 pt 字号下的两个汉字。
- 空段确实会被使用。22 份正式记录中，多数文件有 0 至 2 个空段；复制模板后应保留或按正文结构重新安排空段，不能只看非空段落。
- 6 月主题党日使用了类似讲党课的标题体系，7 月常规记录主要使用 `党建标题` 加 `党建正文`，8 月记录又出现 `党建标题1` 与 `党建正文` 混用。统一模板保留两类标题体系，常规记录使用 `党建标题1` 和 `党建正文`，长记录可继续使用层级标题。

## 字符间距、行距和段距

### 字符间距

- `党建标题`、`党建标题1`、`党建正文`：未写额外 `w:spacing`，有效字符间距视为 0 pt。
- `全文一级大标题`、`正文 文本`、`正文一级标题`、`正文二级标题`：显式设置字符间距为 0 pt。
- `w:kern` 只表示从指定字号起启用字距调整。`党建正文` 和 `党建标题` 的阈值为 1 pt，`党建标题1` 的阈值为 22 pt。它不是字间加宽值。
- 生成材料时不要为了“整齐”统一增加字符间距。需要控制行宽时，优先保持原模板字体、字号和缩进。

### 行距

| 样式 | 原始设置 | 解释 |
| --- | --- | --- |
| `党建标题` | `720`/`exact` | 固定值 36 pt |
| `党建正文` | `620`/`exact` | 固定值 31 pt |
| `党建标题1` | `23`/`atLeast` | 最小行高设置，实际由 22 pt 字体撑开 |
| `全文一级大标题` | `640`/`exact` | 固定值 32 pt |
| `正文 文本` | `560`/`exact` | 固定值 28 pt |
| `正文一级标题` | `560`/`exact` | 固定值 28 pt |
| `正文二级标题` | `560`/`exact` | 固定值 28 pt |

常规记录中，`党建正文` 的 31 pt 固定行距比普通 16 pt 正文更宽松，是当前版式的重要特征。讲党课和部分长记录的正文为 28 pt 固定行距。不要用单一“1.5 倍行距”覆盖两种体系。

### 段前段后

- 22 份正式记录的有效段前、段后均为 0 pt。
- `全文一级大标题`、`正文 文本`、`正文一级标题`、`正文二级标题` 在 XML 中显式写为 0。
- `党建标题`、`党建标题1`、`党建正文` 通常不单独设置段前段后，继承后有效值仍为 0。
- 需要增加视觉间隔时，优先沿用模板中的空段、标题样式或分页方式，不要全局增加段前或段后。

### 空段

- 22 份正式记录中，多数文件有 0 至 2 个空段，常见情况是 1 个。
- 空段的样式并不统一，可能是 `Normal`、`党建正文` 或 `党建标题`。
- 复制模板生成新材料时，应保留空段的位置、数量和样式，或在结构检查后按实际段落关系调整。

3 份学习原文与正式记录使用相同的 A4 页面和页边距，但样式体系不同，不能作为生成正式记录的模板。

| 样式 | 字体和字号 | 对齐 | 首行缩进 | 段前段后 | 行距 | 字符间距 |

| `Normal (Web)` | 仿宋_GB2312 16 pt，个别楷体或 12 pt 变体 | 两端对齐 | 640 至 643 twips，约 1.129 至 1.134 cm | 0 pt | `w:line=30`，`atLeast` | 0 pt |

## 生成与核验规则

1. 所有生成文件统一从 `templates/standard-party-template.docx` 创建，不在运行时选择或读取往月记录。
2. 不使用普通 `Normal` 或 `Normal (Web)` 重建党建记录。
3. 保留统一模板的页面、样式名称、字体、字号、固定行距和文档网格。
4. `党建正文` 默认保留 640 twips 首行缩进。活动时间、地点、参与人员等元数据若原模板左对齐且无首行缩进，只对相应段落做直接覆盖，不修改全局样式。
5. 标题段使用原模板对应的标题样式。短记录优先使用 `党建标题` 或 `党建标题1`，长记录优先沿用 `全文一级大标题`、`正文一级标题`、`正文二级标题` 和 `正文 文本`。
6. 不以临时排版为由把固定行距改成 1.5 倍行距，也不新增字符间距或段前段后；如需统一调整，应修改模板构建器并重新生成标准模板。
7. 生成后使用结构化剖析核对样式和有效格式：

```bash
python scripts/profile_docx_formatting.py \
  --root <党建根目录> \
  --month 6月 \
  --month 7月 \
  --month 8月 \
  --include-source \
  --json
```

本文件中的 1 twip 等于 1/20 pt，567 twips 约等于 1 cm。所有数值只作为统一模板的格式依据和生成结果核对基线。
